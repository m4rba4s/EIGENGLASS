# VISUAL RENDER LAB (VULKAN & GPU PIPELINE)

## 1. Zero-Friction Math-to-GPU
Рендер не должен пересчитывать математику; его задача — чисто визуализировать состояния тензорного поля.
- CPU отправляет на GPU:
  1. SSBO (Shader Storage Buffer Object) с позициями частиц (SoA формат).
  2. Uniform Buffer с глобальной Трансформационной Матрицей (для камеры и базового пространства).
  3. Массив Метрического Тензора (для искривления пространства).

## 2. Compute Shaders (Ray Marching)
Для отрисовки неявных функций (например, фракталов, 4D-аттракторов в 3D-проекции) используется Ray Marching:
- GPU пускает лучи для каждого пикселя.
- Вдоль луча вычисляется функция Signed Distance Field (SDF).
- SDF задается математически, скомпилированным "на лету" из AST дерева, которое ввел пользователь.

## 3. The Grid & Basis Vectors
Лаборатория обязана показывать базисные векторы (i, j, k). 
- При умножении на матрицу A, сетка должна плавно интерполироваться (Linear Interpolation или Slerp для кватернионов) из начального состояния в трансформированное: $X_{render} = X_{initial} + t(AX_{initial} - X_{initial})$. 
- Это позволяет студентам визуально понять, что делает матрица (сдвиг, поворот, масштабирование).

## 4. Telemetry Overlay
UI-слой (ImGui или кастомный) рендерит поверх симуляции:
- CPU GFLOPS.
- RAM/VRAM Bandwidth.
- Текущие Eigenvalues/Eigenvectors матрицы на экране в реальном времени.
